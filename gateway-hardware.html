Gateway - Sơ đồ Kết nối Phần cứng

ESP32 DevKit V1 + LoRa AS32-TTL-100 + WiFi + USB Power

Giao tiếp LoRa

  • • Module: AS32-TTL-100 (SX1278)
  • • Tần số: 433 MHz
  • • Giao thức: UART (Serial2)
  • • GPIO: 16(RX), 17(TX), 4(MD0), 5(MD1), 13(AUX)
  • • Nhận từ 1-3 sensor nodes

Kết nối WiFi & Server

  • • WiFi: 2.4GHz 802.11n (built-in ESP32)
  • • Cấu hình: Captive Portal (lần đầu)
  • • Server: HTTP POST JSON batch
  • • Endpoint: /api/v1/telemetry
  • • Buffer: Ring buffer 10 gói (ISR-safe)

Nguồn điện

  • • Nguồn: USB 5V/2A (Micro USB)
  • • Adapter cắm điện 220V
  • • Lắp cố định (không di động)
  • • Không cần pin (luôn có điện)
  • • Tiêu thụ: ~200-300mA (WiFi + LoRa)
